이 페이지는 로그인 없이 열 수 있습니다.

Google Play용 픽AI 계정·데이터와 통합·공유되지 않습니다. Google 앱 탈퇴는 별도 안내를 이용하세요.

1. 앱에서 계정을 삭제하는 방법

토스 로그인 상태에서 아래 경로로 이동합니다.

  1. 토스 앱에서 픽AI 미니앱을 실행합니다.
  2. 하단 MY 탭을 엽니다.
  3. 회원 탈퇴 메뉴를 누르거나, 설정 → 계정 삭제 화면으로 이동합니다.
  4. 화면 안내에 따라 삭제를 확인합니다.

토스 픽AI 앱은 PICKAI API 주소가 설정되고 토스 로그인된 상태에서 「회원 탈퇴」 화면의 「탈퇴하기」로 POST /auth/delete-account(Bearer = Supabase access JWT)를 호출합니다. API 주소가 없거나 로그인되지 않으면 탈퇴 요청을 할 수 없습니다.

현재 운영(2026-10-10 읽기 전용 점검): 서버에서 Supabase Auth 삭제 게이트가 비활성이면 「탈퇴하기」는 503(supabase-auth-delete-disabled)로 실패하고, 앱은 오류를 표시합니다(성공 시에만 로컬 데이터를 제거하는 구현). 이 경우 서버 SQLite·Supabase Auth 사용자는 삭제되지 않습니다. 게이트 활성화·별도 승인 후에만 아래 전체 삭제 흐름이 완료됩니다.

서버는 (1) SQLite의 사용자·연관 데이터를 삭제하고 삭제 작업을 기록한 뒤, (2) 서버 환경에서 Supabase Auth 삭제가 활성화된 경우 Supabase Auth 사용자를 삭제합니다. Supabase 삭제가 실패하면 작업 상태가 남으며, 동일 JWT로 탈퇴를 재시도하거나(로그인 가능 시) 서버 내부 복구(운영 설정)로 마무리할 수 있습니다. 탈퇴 진행·완료 후에는 동일 JWT로 서버에 계정이 재생성되지 않습니다.

로그아웃만 하면 sessionStorage의 액세스·리프레시 토큰이 제거되지만, 서버에 남은 계정·기록은 삭제되지 않습니다. 완전 탈퇴는 계정 삭제를 이용하세요.

2. 앱에 접속할 수 없을 때

미니앱을 열 수 없거나 로그인할 수 없으면 아래 이메일로 삭제를 요청할 수 있습니다. 이메일 요청만으로 자동 API 삭제는 수행되지 않습니다. 운영자가 수동으로 본인 확인 후 처리합니다. 본인 확인 없이 즉시 삭제하지 않을 수 있습니다.

앱 내 탈퇴는 POST /auth/delete-account에 유효한 Supabase access JWT가 있을 때만 해당 JWT의 sub 계정을 삭제합니다(서비스 롤·관리자 키는 앱에 없음).

3. 삭제되는 데이터(서버, 계정 삭제 성공 시)

토스 전용 API deleteUserAccount 흐름에 따라, 해당 내부 사용자 ID에 연결된 데이터가 삭제됩니다. 예:

  • 사용자 계정 행( synthetic 이메일, 닉네임, 내부 ID 등)
  • 관심종목, AI 분석 기록
  • 포인트 지갑, 포인트 거래·예약
  • 소셜 연동·제공자 토큰 — 토스 로그인만 사용 시 Google/Naver 연동 행은 없을 수 있음
  • 투자 부적·유료 분석 등 서버에 저장된 이용 기록 — 기능 이용·연동된 경우

Supabase Auth 사용자가 삭제되면 해당 계정의 refresh 토큰·세션은 더 이상 유효하지 않습니다. access JWT는 만료 전까지 서명 검증만 통과할 수 있으나, 위 재생성 차단으로 서비스 이용은 되지 않습니다.

Supabase Auth 사용자 삭제는 서버 환경 변수로 제어됩니다(배포 예시 파일 기준 기본 비활성). 활성화된 환경에서만 service role로 Auth 사용자를 삭제합니다. 미완료 작업은 account_deletion_jobs에 남고, 운영 설정 시 JWT 없이 내부 복구를 시도할 수 있습니다.

미완료 탈퇴 작업(account_deletion_jobs.phase = sqlite_deleted)에 대한 자동 알림·대시보드·주기 스케줄은 코드에 없습니다. PICKAI_TOSS_ACCOUNT_DELETION_RECOVERY_ENABLED=1일 때 서버 기동 후 1회 sweep 및 처리 건수 로그만 기록합니다.

운영 env(2026-10-10 읽기 전용 점검): PICKAI_TOSS_SUPABASE_AUTH_DELETE_ENABLED· PICKAI_TOSS_ACCOUNT_DELETION_RECOVERY_ENABLED는 비활성(미설정 또는 0)이었습니다. 미완료 job에 대한 자동 알림·대시보드·주기 스케줄은 없습니다. 복구 env=1이고 Auth 삭제가 활성화된 경우에만 기동 1회 sweep 및 처리 건수 로그가 있습니다. 출시 전 게이트 활성화·운영 runbook은 별도 승인 후 정합니다.

4. 기기(로컬)에서 제거되는 데이터

탈퇴 성공 시 앱은 로그아웃 처리 후 아래 로컬 데이터를 제거합니다. 로그아웃만 하면 세션만 제거됩니다.

  • sessionStorage: 로그인 세션(access·refresh 토큰, userKey)
  • localStorage: 로컬 차트·전망 분석 기록, 투자 부적 목록, 로컬 관심종목, 최근 본 종목 등

로컬 삭제 대상에는 차트·전망 분석 기록, 투자 부적 목록, 로컬 관심종목, 최근 본 종목, 종목 디렉터리 캐시 등이 포함됩니다.

5. 삭제 후에도 남을 수 있는 데이터

  • 서버·Supabase·호스팅 운영 로그(요청 시각, 경로, 오류, 내부 사용자 ID 등) — 보관 기간·접근은 개인정보처리방침 §2.5·§3(법무·운영 검토 대기)과 동일하게 확정 후 기재
  • 법령상 보관 의무가 있는 기록 — 현재 토스 결제 미연동 시 해당 없을 수 있음

토스 앱 계정·토스 금융 계정 자체는 픽AI가 삭제하지 않습니다. 픽AI 토스 미니앱 서비스 데이터만 삭제합니다.

6. Google Play 픽AI와의 관계

Android Google Play 앱의 계정·포인트·기록은 이 절차로 삭제되지 않습니다. Google 앱 탈퇴는 별도 앱 또는 Google 앱 계정 삭제 안내를 이용하세요.
